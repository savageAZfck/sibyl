# Security

Report vulnerabilities privately to savagetism@icloud.com — do not open
public issues for exploitable weaknesses.

Scope: AES-256-GCM payload sealing, two-share custody arithmetic, commitment correctness, oracle release-artifact verification, gate-log hash-chaining.

Out of scope: oracle honesty (an oracle that leaks its share early breaks the gate), and post-release handling of the disclosed payload (see THREAT_MODEL.md).
